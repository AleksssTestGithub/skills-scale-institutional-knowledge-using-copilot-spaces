# OctoAcme Project Management Docs

This folder is the entry point for OctoAcme’s project management process docs.
Use it to understand the full lifecycle from initiation through planning, execution, release, and continuous improvement.

## Process Overview

OctoAcme uses a lightweight, iterative project management approach with clear ownership, visible tracking, proactive risk management, and regular communication.
The core flow is:

1. **Project management overview** — principles, roles, artifacts, and lifecycle
2. **Project initiation** — define the problem, stakeholders, success criteria, and go/no-go decision
3. **Project planning** — turn approved work into an actionable backlog and release plan
4. **Execution and tracking** — manage delivery, quality checks, and progress reporting
5. **Risk management and communication** — identify, assess, and escalate risks and updates
6. **Release and deployment** — standardize production releases and post-deploy verification
7. **Retrospective and continuous improvement** — capture learnings and improve the process
8. **Roles and personas** — clarify common responsibilities used across the docs
